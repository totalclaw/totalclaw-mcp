# 下架记录（2026-11-02）

下架方式：**不删清单文件**，在清单里置 `verified: false`、`security.scan_verdict: block`，并把理由写进 `security.reason`（随 `registry.json` 下发）。
原因：桌面端 `mcpRegistry.ts` 对 `block` 的条目市场里不列出；同时按 `block` 名单把本机**已经装了**的同名连接器停掉——清单删了桌面端就认不出来了。
`name` / `runtimes` 等标识原样保留，安装器对 `block` 永不安装。
