下面 2 条在清单层面无解，经负责人确认下架。

| 条目 | 清单 | 包 | 理由 |
|---|---|---|---|
| browser_use | `registry/servers/web/browser_use` | `browser-use-mcp-server==1.0.3` | 没有真正的 stdio 模式：`--stdio` 是起 8000 端口 SSE 服务再拉起外部 `mcp-proxy`（不在依赖里）；写死 OpenAI gpt-4o（需 `OPENAI_API_KEY`）、需本机 Playwright 浏览器；依赖 browser-use 未设上界，0.6 起删了它导入的 `browser_use.browser.browser`，钉回 0.1.40 能过导入仍起不来 |
| database | `registry/servers/data/database` | `database-mcp==0.1.4` | 依赖链 `legion-query-runner` 所有版本硬依赖 `mysqlclient==2.1.1`，只有 Windows 预编译包，macOS / Linux 要本机装 MySQL 开发库现场编译，普通用户装不上 |

## 要恢复

- `database`：上游把 mysqlclient 换成纯 Python 驱动（如 PyMySQL）或改为可选依赖后恢复。
