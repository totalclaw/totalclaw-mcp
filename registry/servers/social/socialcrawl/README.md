# SocialCrawl

27 社交平台公开数据爬取:账号资料、帖子、搜索、分析。5 工具:list_platforms / list_endpoints / request / check_balance / get_docs。前 3 个无 key 可用,request + balance 需 key。

## 安装前置

npm install -g socialcrawl-mcp 或 npx 自动拉。

**鉴权**：SOCIALCRAWL_API_KEY(sc_ 前缀,socialcrawl.dev 申请)

来源：https://github.com/socialcrawl/mcp

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
