# MatrixMedia 媒体矩阵

媒体矩阵账号管理 + 视频跨平台批量发布 + 发布历史查询;提供 list_accounts / list_history / publish_video 3 个工具。

## 安装前置

git clone https://github.com/hanliang97/MatrixMedia && cd MatrixMedia/mcp && npm install && npm run build。MATRIXMEDIA_DIR 指向仓库根绝对路径。

**鉴权**：无 token,但 MATRIXMEDIA_DIR 必须指向本地仓库

来源：https://github.com/hanliang97/MatrixMedia

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
