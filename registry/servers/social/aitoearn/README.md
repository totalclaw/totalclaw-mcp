# AiToEarn

13+ 社交平台统一发布(视频/图文) + 自动点赞/评论/回复 + AI 文案生成 + 任务化变现执行。统一 unified MCP 接口。国内站点改 base 为 https://aitoearn.cn/api。

## 安装前置

在 aitoearn.ai 注册账号,后台领 RELAY_API_KEY。无须本地进程。

**鉴权**：RELAY_API_KEY(x-api-key header)

来源：https://github.com/yikart/AiToEarn
