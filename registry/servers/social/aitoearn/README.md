# AiToEarn

13+ 社交平台统一发布(视频/图文) + 自动点赞/评论/回复 + AI 文案生成 + 任务化变现执行。统一 MCP 接口。国内站点改 url 为 https://aitoearn.cn/api/ai/agent/mcp。

## 安装前置

在 aitoearn.ai 注册账号，首次使用时通过浏览器完成 OAuth 登录授权。无须本地进程。

**鉴权**：OAuth 浏览器登录授权（标准 MCP OAuth 2.1 + 动态注册）

来源：https://github.com/yikart/AiToEarn

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
