# PostgreSQL

PostgreSQL 只读查询 — 暴露 query / schema / 表元信息工具。Connection string 在 args 末。已归档但仍可用。

## 安装前置

``POSTGRES_URL=postgres://user:pass@host:port/db`` 形式。推荐建只读账号。

**鉴权**：POSTGRES_URL(含密码)
