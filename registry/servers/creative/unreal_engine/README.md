# Unreal Engine

Drive Unreal Editor 5.8+ through Epic's experimental MCP toolset registry: scene, asset, Blueprint, Sequencer, PIE, automation, capture, and editor scripting workflows.

## 安装前置

Enable Unreal MCP and Toolset Registry in the editor, enable Auto Start Server under Model Context Protocol preferences, then set enabled:true. Default endpoint is 127.0.0.1:8000/mcp.

**鉴权**：none; loopback-only endpoint

来源：https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
