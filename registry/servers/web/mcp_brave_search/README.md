# Brave Search

Brave 搜索 API — web_search / local_search。隐私友好的搜索后端,与 LLM 主搜索流互补。已归档但仍可用。

## 安装前置

在 https://api.search.brave.com 注册 + 领 API key。免费额度 2000 query/月。

**鉴权**：BRAVE_API_KEY

来源：https://github.com/modelcontextprotocol/servers-archived
