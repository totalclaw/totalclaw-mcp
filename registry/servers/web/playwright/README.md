# Playwright

微软 Playwright MCP — 跨浏览器(Chromium/Firefox/WebKit)自动化 + 截图 + 网络拦截 + accessibility tree。比 chrome_devtools 跨浏览器、accessibility 信息更丰富。由微软官方维护。

## 安装前置

首次 npx 自动拉 + 浏览器二进制(~300MB)。可加 args ``["--headless"]`` 跑无头模式。

**鉴权**：无(本地浏览器)

来源：https://github.com/microsoft/playwright-mcp

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
