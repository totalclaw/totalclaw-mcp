# Linear

Linear issue tracker 集成 — issue CRUD / 项目 / cycle / team / labels / comments / search。

## 安装前置

在 Linear → Settings → API → Personal API keys 生成。

**鉴权**：LINEAR_API_KEY(lin_api_ 前缀)

来源：https://github.com/tacticlaunch/mcp-linear
