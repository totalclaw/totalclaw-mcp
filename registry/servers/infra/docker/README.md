# Docker

Docker 容器管理 — ps / images / run / stop / logs / exec / inspect / network / volume。LLM 直接调度本地或远端 Docker daemon。

## 安装前置

本机装 Docker;DOCKER_HOST 指 socket(默认 unix socket)或远端 tcp://。

**鉴权**：无(用 Docker daemon 自身权限)

来源：https://github.com/QuantGeekDev/docker-mcp

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
