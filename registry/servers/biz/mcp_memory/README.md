# Memory

知识图谱式持久记忆 — 实体 / 关系 / 观察三元组,跨会话保留。与 totalclaw_core.memory.long_term_memory 互补:本 server 走图谱模型,核内 LTM 走衰减表模型。

## 安装前置

``MEMORY_FILE_PATH`` 指向 JSON 持久化文件。

**鉴权**：无

来源：https://github.com/modelcontextprotocol/servers

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
