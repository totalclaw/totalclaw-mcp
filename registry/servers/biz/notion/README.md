# Notion

Notion API 全套集成 — 页面 / 数据库 / 搜索 / 评论 / 用户 / 块级编辑。Notion 官方维护。

## 安装前置

在 https://www.notion.so/my-integrations 创建集成 + 拷 token,在目标页面/数据库加共享给该集成。

**鉴权**：NOTION_API_KEY(secret_ 前缀)

来源：https://github.com/makenotion/notion-mcp-server

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
