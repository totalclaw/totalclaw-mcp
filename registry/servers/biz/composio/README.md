# Composio

500+ SaaS 工具统一接入枢纽:Gmail / Slack / GitHub / Notion / Linear / Jira / HubSpot / Salesforce / Calendar / Drive 等。支持 OAuth 流程 + 多账号上下文 + 沙箱工作台。

## 安装前置

在 composio.dev / app.composio.dev 注册并领 API key。亦可自托管(见 composio 仓库 docker-compose),URL 改为本地端点。

**鉴权**：COMPOSIO_API_KEY(Bearer)

来源：https://github.com/composiohq/composio

> 由 scripts/import_presets.py 从 totalclaw-agent mcp_presets 导入，名称与 preset 保持一致。
